# HAVENROAST

A coffee shop website built with Astro.

## Tech Stack

* Astro
* Tailwind CSS
* Motion
* Lenis
* Phosphor Icons
* Plus Jakarta Sans

## Features

* Responsive design
* Smooth scrolling
* Page and component animations
* Mobile-friendly layout

## Getting Started

Clone the repository:

```bash
git clone https://github.com/krevindev/HAVENROAST.git
cd HAVENROAST
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:4321` in your browser.

## Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## About

HAVENROAST is a personal web development project made to practice Astro, animations, and responsive web design.
